1) FUNCTION recursiva(n)
------------------------------------------
INICIO recursiva(n)
    SI n no es entero ENTONCES
        LANZAR error de tipo
    SI n < 0 ENTONCES
        LANZAR error de valor (no se permite negativo)
    SI n == 0 ENTONCES
        IMPRIMIR "¡Despegue!"
        REGRESAR
    SINO
        IMPRIMIR n
        LLAMAR recursiva(n - 1)
FIN recursiva

CASO BASE: n == 0
CASO RECURSIVO: n > 0 -> recursiva(n - 1)


2) FUNCTION fibonacci(n)
------------------------------------------
INICIO fibonacci(n)
    SI n no es entero ENTONCES LANZAR error de tipo
    SI n < 0 ENTONCES LANZAR error de valor
    SI n == 0 ENTONCES REGRESAR 0
    SI n == 1 ENTONCES REGRESAR 1
    SINO REGRESAR fibonacci(n - 1) + fibonacci(n - 2)
FIN fibonacci

CASO BASE: n == 0 o n == 1
CASO RECURSIVO: fibonacci(n-1) + fibonacci(n-2)


3) FUNCTION factorial(n)
------------------------------------------
INICIO factorial(n)
    SI n no es entero ENTONCES LANZAR error de tipo
    SI n < 0 ENTONCES LANZAR error de valor
    SI n == 0 ENTONCES REGRESAR 1
    SINO REGRESAR n * factorial(n - 1)
FIN factorial

CASO BASE: n == 0
CASO RECURSIVO: n * factorial(n - 1)


4) FUNCTION multiplicacion_recursiva(a, b)
------------------------------------------
INICIO multiplicacion_recursiva(a, b)
    SI a o b no son enteros ENTONCES LANZAR error de tipo
    SI b < 0 ENTONCES
        REGRESAR -multiplicacion_recursiva(a, -b)
    SI b == 0 ENTONCES REGRESAR 0
    SINO REGRESAR a + multiplicacion_recursiva(a, b - 1)
FIN multiplicacion_recursiva

CASO BASE: b == 0
CASO RECURSIVO: a + multiplicacion_recursiva(a, b - 1)
CASO ESPECIAL: b negativo -> se invierte el signo del resultado


5) FUNCTION division_entera_recursiva(dividendo, divisor)
------------------------------------------
INICIO division_entera_recursiva(dividendo, divisor)
    SI dividendo o divisor no son enteros ENTONCES LANZAR error de tipo
    SI divisor == 0 ENTONCES LANZAR error de división entre cero
    SI dividendo < 0 O divisor < 0 ENTONCES LANZAR error de valor
    SI dividendo < divisor ENTONCES REGRESAR 0
    SINO REGRESAR 1 + division_entera_recursiva(dividendo - divisor, divisor)
FIN division_entera_recursiva

CASO BASE: dividendo < divisor
CASO RECURSIVO: 1 + division_entera_recursiva(dividendo - divisor, divisor)


6) FUNCTION potencia_recursiva(base, exponente)
------------------------------------------
INICIO potencia_recursiva(base, exponente)
    SI base no es numérico ENTONCES LANZAR error de tipo
    SI exponente no es entero ENTONCES LANZAR error de tipo
    SI exponente < 0 ENTONCES
        LANZAR error de valor
        (nunca llegaría al caso base 0, causaría RecursionError)
    SI exponente == 0 ENTONCES REGRESAR 1
    SINO REGRESAR potencia_recursiva(base, exponente - 1) * base
FIN potencia_recursiva

CASO BASE: exponente == 0
CASO RECURSIVO: potencia_recursiva(base, exponente - 1) * base
VALIDACIÓN CLAVE: exponente negativo se rechaza antes de recursar


7) FUNCTION serie_collatz(n)
------------------------------------------
INICIO serie_collatz(n)
    SI n no es entero ENTONCES LANZAR error de tipo
    SI n <= 0 ENTONCES
        LANZAR error de valor
        (n = 0 nunca llega a 1; negativos tampoco)
    SI n == 1 ENTONCES
        IMPRIMIR "END!"
        REGRESAR 0
    SINO
        SI n es par ENTONCES
            IMPRIMIR n // 2
            REGRESAR serie_collatz(n // 2)
        SINO
            IMPRIMIR 3 * n + 1
            REGRESAR serie_collatz(3 * n + 1)
FIN serie_collatz

CASO BASE: n == 1
CASO RECURSIVO: n par -> serie_collatz(n // 2)
                n impar -> serie_collatz(3n + 1)
VALIDACIÓN CLAVE: n debe ser entero positivo (> 0) antes de recursar


8) FUNCTION aplanar_json(diccionario, clave_padre, separador)
------------------------------------------
INICIO aplanar_json(diccionario, clave_padre = '', separador = '.')
    SI diccionario no es de tipo dict ENTONCES
        LANZAR error de atributo (ej. si es una lista)
    CREAR lista vacía "elementos"
    PARA CADA (key, value) EN diccionario.items() HACER
        nueva_llave = clave_padre + separador + key (si clave_padre existe)
                      SINO nueva_llave = key
        SI value es un dict ENTONCES
            elementos += aplanar_json(value, nueva_llave, separador).items()
        SINO
            elementos.agregar((nueva_llave, value))
    REGRESAR diccionario construido a partir de elementos
FIN aplanar_json

CASO BASE (implícito): value no es un dict -> se agrega directo, no se recursa más
CASO RECURSIVO: value es un dict -> aplanar_json(value, nueva_llave, separador)
NOTA: las listas no se aplanan, se guardan como valor tal cual.
NOTA: llaves duplicadas (colisión) se sobrescriben sin aviso.
